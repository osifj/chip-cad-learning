# 7 天零基础学习计划

目标：7 天后，你能跑通项目、解释每个模块在做什么，并把它讲成一个真实可信的 EDA / IC CAD 自动化实习项目。

## Day 0：环境准备

今天学什么：准备 Mac Terminal、VMware Ubuntu、Python 依赖和项目自检。

为什么学这个：环境不通，后面所有脚本都跑不起来。

先看文档：

- `docs/零基础完整运行手册.md`
- `docs/VMware_Ubuntu_零基础操作手册.md`

运行命令：

```bash
cd /Users/dep/Documents/Codex/2026-05-25/7-1-2-3-reference-flow
python3 -m pip install -r requirements.txt
bash scripts/check_all.sh
```

观察什么：

- `pwd` 是否在项目根目录。
- 自检是否出现 `[OK]`。
- 如果有 `[FAIL]`，能不能按提示修。

今天要能讲出来：我知道 Terminal 是输入命令的地方，也知道如何确认自己在正确目录。

小练习：运行 `pwd`、`ls`、`cd docs`、`cd ..`，说出每条命令做了什么。

面试积累一句话：我能在 Mac 或 Linux 环境下准备项目依赖，并用自检脚本验证基础工具链。

## Day 1：Linux / Terminal 基础

今天学什么：`pwd`、`ls`、`cd`、路径、文件夹、命令输出。

为什么学这个：EDA 自动化实习几乎每天都要在 Linux 服务器上找目录、跑脚本、看 log。

先看文档：

- `docs/命令逐行解释手册.md` 的基础命令部分
- `docs/VMware_Ubuntu_零基础操作手册.md`

运行命令：

```bash
pwd
ls
cd 01-shell环境脚本学习
pwd
ls
cd ..
```

观察什么：

- 进入子目录后 `pwd` 结尾是否变化。
- `ls` 能否看到对应脚本。

今天要能讲出来：路径就是文件夹位置，命令要在正确目录运行。

小练习：分别进入 01、02、03、04、05 文件夹，然后回到根目录。

面试积累一句话：我熟悉基本 Linux 命令，能在项目目录中定位脚本、输入文件和输出文件。

## Day 2：Shell 自动化

今天学什么：Week 1 环境检查脚本。

为什么学这个：CAD 工程师常常需要设置 EDA 工具路径、license、PDK 环境变量。

先看文档：

- `01-shell环境脚本学习/README.md`
- `docs/命令逐行解释手册.md` 的 Week 1 部分

运行命令：

```bash
cd 01-shell环境脚本学习
./eda_env_setup.sh --check-only
SIMULATE=true ./eda_env_setup.sh
cd ..
```

观察什么：

- 哪些工具是 `[PASS]`。
- Mac 上是否提示 `make` 版本偏旧。
- `SIMULATE=true` 和普通运行有什么区别。

今天要能讲出来：`PATH` 是命令搜索路径，`LM_LICENSE_FILE` 是 license 服务器地址，Shell 可以把环境配置自动化。

小练习：打开 `config/default.conf`，找出 `CAD_ROOT` 和 `PDK_NAME`。

面试积累一句话：我做了一个 Shell 环境初始化脚本，用于检查系统依赖并模拟配置 EDA 工具环境变量。

## Day 3：Tcl 日志解析

今天学什么：Week 2 Tcl parser。

为什么学这个：EDA 工具会产生大量 log，实习生常见任务是提取 warning、error、slack、area 等信息。

先看文档：

- `02-tcl-log解析器/README.md`
- `docs/命令逐行解释手册.md` 的 Week 2 部分

运行命令：

```bash
cd 02-tcl-log解析器
tclsh eda_report_parser.tcl sample_logs/dc_synthesis.log -summary
tclsh eda_report_parser.tcl sample_logs/pt_timing.log -json
mkdir -p reports
tclsh eda_report_parser.tcl sample_logs/dc_synthesis.log -o reports/dc_report.txt
cd ..
```

观察什么：

- `slack` 是否为负数。
- `violated` 和 `warn` 是多少。
- `reports/dc_report.txt` 是否生成。

今天要能讲出来：Tcl parser 读取 log 文件，用正则匹配提取指标，再输出 text/json/csv/summary。

小练习：在 sample log 中搜索 `Warning:`，对比脚本输出的 warning 数量。

面试积累一句话：我用 Tcl 实现了 EDA log parsing，能从 DC/PT log 自动提取 timing、area、power 和 warning 摘要。

## Day 4：Python 测试数据分析

今天学什么：Week 3 testchip CSV 分析。

为什么学这个：JD 里提到 IP 流片测试数据收集、管理及分析流程自动化。

先看文档：

- `03-python测试数据流水线/README.md`
- `docs/命令逐行解释手册.md` 的 Week 3 部分

运行命令：

```bash
cd 03-python测试数据流水线
python3 scripts/analyze_testchip.py data/testchip_measurements.csv --no-plot
python3 scripts/analyze_testchip.py data/testchip_measurements.csv --report html
ls outputs
cd ..
```

观察什么：

- CSV 有多少行、多少列。
- Yield 是否为 `97.5%`。
- `outputs/analysis_report.txt` 和 HTML/图片是否生成。

今天要能讲出来：良率 yield = passed dies / total dies；Python 可以把测试数据自动变成报告。

小练习：打开 CSV，找到 `pass_flag` 这一列，数一下失败 die。

面试积累一句话：我用 Python/pandas 处理 testchip CSV，自动输出良率、wafer 统计、speed bin 分布和参数统计报告。

## Day 5：Makefile / Flow 自动化

今天学什么：Week 4 Makefile reference flow。

为什么学这个：EDA flow 自动化是 IC CAD 实习的核心场景之一。

先看文档：

- `04-eda流程自动化框架/README.md`
- `docs/命令逐行解释手册.md` 的 Week 4 部分

运行命令：

```bash
cd 04-eda流程自动化框架
make clean
make all
make status
ls logs
cd ..
```

观察什么：

- 每一步是否 `[OK]`。
- `logs/` 是否生成 6 个 log。
- `flow/.synth_done` 等状态文件是否存在。

今天要能讲出来：Makefile 把流程步骤串起来，`.done` 文件用于断点续跑。

小练习：运行 `make clean` 后再运行 `make status`，观察状态变化。

面试积累一句话：我用 Makefile 模拟了 synth、place、CTS、route、STA、PV 的 reference flow，并实现了日志和断点续跑机制。

## Day 6：chipcad 工具箱整合

今天学什么：Week 5 统一 CLI。

为什么学这个：真实团队会把常用脚本封装成内部工具，减少重复操作。

先看文档：

- `05-chipcad工具箱与AI部署/README.md`
- `docs/命令逐行解释手册.md` 的 Week 5 部分

运行命令：

```bash
./05-chipcad工具箱与AI部署/chipcad.sh
./05-chipcad工具箱与AI部署/chipcad.sh env check
./05-chipcad工具箱与AI部署/chipcad.sh parse 02-tcl-log解析器/sample_logs/dc_synthesis.log --format summary
./05-chipcad工具箱与AI部署/chipcad.sh analyze 03-python测试数据流水线/data/testchip_measurements.csv --no-plot
./05-chipcad工具箱与AI部署/chipcad.sh flow status
```

观察什么：

- chipcad 是否能调用前四周工具。
- 默认输出路径是否合理。
- 哪个命令对应哪一周。

今天要能讲出来：chipcad 是统一入口，底层仍然调用 Shell、Tcl、Python 和 Makefile。

小练习：运行 `chipcad ai prompt` 生成一个 prompt，并找到保存的文件。

面试积累一句话：我把多个 CAD 自动化 demo 封装成统一 CLI，模拟内部工具箱的使用方式。
