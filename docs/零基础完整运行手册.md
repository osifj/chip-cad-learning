# 零基础完整运行手册

这份手册面向真正第一次接触 EDA / IC CAD / Linux / Shell / Tcl / Python 自动化的同学。你可以把它当成“从打开电脑到跑通项目”的总入口。

## 1. 这个项目是什么

这个仓库叫 `chip-cad-learning`，它不是商业软件，也不是完整芯片设计平台。它是一个面向 EDA / IC CAD 实习的训练项目，把实习岗位常见工作拆成 5 个小工具：

| 模块 | 你在学什么 | 对应实习工作 |
|---|---|---|
| 01 Shell 环境脚本 | 用命令行检查软件、设置环境变量 | 工作环境配置、EDA tool setup |
| 02 Tcl log 解析器 | 从 EDA 日志里提取 area、power、slack、warning | Log parsing、IP QA、report automation |
| 03 Python 测试数据流水线 | 读取 CSV，计算良率，生成报告 | Testchip data analysis、测试数据处理 |
| 04 Makefile flow | 把综合、布局、CTS、布线、STA、PV 串成流程 | Reference Flow、EDA flow automation |
| 05 chipcad 工具箱 | 用一个统一命令调用前面所有工具 | 内部工具封装、AI 辅助脚本支持 |

Shell（命令行脚本）用于自动执行系统命令。EDA 环境里经常要设置 `PATH`、`LM_LICENSE_FILE`、工具路径，手动做容易错，所以用 Shell 自动化。

Tcl 是很多 EDA 工具内置的脚本语言。Synopsys、Cadence 等工具常用 Tcl 写流程脚本、读报告、改约束、查 timing。

Python 数据分析用于处理测试芯片或 IP 测试结果。真实工作里常见输入是 CSV、Excel、数据库导出的数据，输出是 yield、统计表、图表和异常点。

Makefile / Flow 用来描述“先做 A，再做 B，失败了停在哪里”。真实芯片流程里，综合、布局布线、时序分析、物理验证都需要流程编排。

chipcad 工具箱是一个统一入口。你不用记住 5 个目录里的所有命令，可以用 `chipcad env check`、`chipcad parse`、`chipcad analyze` 等命令调用。

## 2. 我应该怎么学习

不要先背代码。按这个顺序来：

1. 第 0 步：准备环境。确认你有 Mac Terminal，最好也能打开 VMware Ubuntu。
2. 第 1 步：学会打开终端。Terminal 就是输入命令的地方。
3. 第 2 步：进入项目目录。用 `cd` 进入仓库根目录。
4. 第 3 步：运行第一个命令。先跑 `bash scripts/check_all.sh`。
5. 第 4 步：理解输出。看到 `[OK]` 代表这一步通过，看到 `[FAIL]` 就按提示修。
6. 第 5 步：修改一个小功能。比如多解析一个 warning，或改报告里的文字。
7. 第 6 步：整理成面试说法。你要能说出“我做了什么、输入是什么、输出是什么、为什么有用”。

## 3. Mac 上怎么运行

### 3.1 打开 Terminal

Terminal 是 macOS 上输入命令的程序。打开方式：

1. 按 `Command + Space` 打开 Spotlight 搜索。
2. 输入 `Terminal` 或“终端”。
3. 回车打开。

打开后你会看到类似：

```text
dep@MacBookAir ~ %
```

这个窗口里可以输入命令。输入完按回车执行。

### 3.2 三个最基本命令

```bash
pwd
```

`pwd` 是 print working directory，意思是“显示我现在在哪个文件夹”。成功后会输出一个路径，例如：

```text
/Users/dep
```

```bash
ls
```

`ls` 是 list，意思是“列出当前文件夹里的文件”。成功后会看到文件和文件夹名字。

```bash
cd /Users/dep/Documents/Codex/2026-05-25/7-1-2-3-reference-flow
```

`cd` 是 change directory，意思是“进入某个文件夹”。这条命令会进入本项目的根目录。

### 3.3 确认自己在正确目录

进入项目后运行：

```bash
pwd
ls
```

正常应该看到路径包含：

```text
/Users/dep/Documents/Codex/2026-05-25/7-1-2-3-reference-flow
```

`ls` 应该能看到：

```text
01-shell环境脚本学习
02-tcl-log解析器
03-python测试数据流水线
04-eda流程自动化框架
05-chipcad工具箱与AI部署
README.md
docs
requirements.txt
```

### 3.4 安装 Python 依赖

在项目根目录运行：

```bash
python3 -m pip install -r requirements.txt
```

含义：

- `python3`：使用 Python 3。
- `-m pip`：调用 Python 的包管理器 pip。
- `install`：安装。
- `-r requirements.txt`：按 `requirements.txt` 文件里的列表安装。

正常输出会出现 `Successfully installed` 或 `Requirement already satisfied`。

### 3.5 运行一键自检

```bash
bash scripts/check_all.sh
```

这会检查 Python、pip、Tcl、make，并运行关键 demo。成功时会看到多行 `[OK]`，最后看到：

```text
All core demos passed.
```

如果看到 `[FAIL] pandas not installed`，运行：

```bash
python3 -m pip install -r requirements.txt
```

### 3.6 逐个模块运行

在项目根目录运行以下命令。

Week 1：

```bash
cd 01-shell环境脚本学习
./eda_env_setup.sh --check-only
cd ..
```

作用：检查 gcc、make、python3、tclsh 等工具是否存在。

Week 2：

```bash
cd 02-tcl-log解析器
tclsh eda_report_parser.tcl sample_logs/dc_synthesis.log -summary
cd ..
```

作用：解析模拟 DC 综合 log，输出 area、power、cells、slack、warning。

Week 3：

```bash
cd 03-python测试数据流水线
python3 scripts/analyze_testchip.py data/testchip_measurements.csv --no-plot
cd ..
```

作用：读取测试芯片 CSV，计算良率和参数统计，输出 `outputs/analysis_report.txt`。

Week 4：

```bash
cd 04-eda流程自动化框架
make status
make all
cd ..
```

作用：查看并运行模拟 EDA flow。输出 log 在 `04-eda流程自动化框架/logs/`。

Week 5：

```bash
./05-chipcad工具箱与AI部署/chipcad.sh parse 02-tcl-log解析器/sample_logs/dc_synthesis.log --format summary
./05-chipcad工具箱与AI部署/chipcad.sh analyze 03-python测试数据流水线/data/testchip_measurements.csv --no-plot
./05-chipcad工具箱与AI部署/chipcad.sh flow status
```

作用：用统一入口调用 Week 2、Week 3、Week 4。

## 4. VMware Ubuntu 中怎么运行

VMware 是虚拟机软件。它可以在 Mac 里开一个 Linux 系统。Ubuntu 是 Linux 的一种发行版。EDA / IC CAD 实习常用 Linux，因为很多 EDA 工具、license、脚本环境都部署在 Linux 服务器上。

### 4.1 打开虚拟机

1. 打开 VMware Fusion 或 VMware Workstation。
2. 在虚拟机列表里找到你的 Ubuntu / Linux 虚拟机。
3. 点击虚拟机，再点击启动按钮。
4. 等待进入桌面或登录界面。

如果名字显示 Ubuntu，但系统实际是 CentOS，也没关系。对这个项目来说，命令行用法基本一样。

### 4.2 打开 Ubuntu Terminal

进入桌面后，有三种常见方式：

1. 按快捷键 `Ctrl + Alt + T`。
2. 点击左下角或左上角应用菜单，搜索 `Terminal`。
3. 在桌面空白处右键，选择 `Open in Terminal`。

Terminal 打开后，你会看到类似：

```text
dep@ubuntu:~$
```

这里就是输入 Linux 命令的地方。

### 4.3 查看当前路径和项目目录

```bash
pwd
ls
```

如果项目已经在 Ubuntu 里，常见路径是：

```bash
cd ~/chip-cad-learning
```

`~` 代表当前用户的 home 目录，例如 `/home/dep`。

确认成功：

```bash
pwd
ls
```

应该看到 `README.md`、`01-shell环境脚本学习` 等目录。

### 4.4 查看 Ubuntu IP

在 Ubuntu Terminal 输入：

```bash
hostname -I
```

正常会输出一个或多个 IP，例如：

```text
192.168.210.128
```

这个 IP 是 Mac 通过 SSH 连接虚拟机时要用的地址。

### 4.5 从 Mac 连接 Ubuntu

在 Mac Terminal 输入：

```bash
ssh dep@192.168.210.128
```

把 `192.168.210.128` 换成你在 Ubuntu 里看到的 IP。

含义：

- `ssh`：远程登录 Linux。
- `dep`：Ubuntu 用户名。
- `@192.168.210.128`：要连接的机器 IP。

第一次连接可能会问：

```text
Are you sure you want to continue connecting?
```

输入 `yes` 回车。然后输入密码。输入密码时屏幕不会显示字符，这是正常的。

连接成功后，你会看到 Linux 提示符，例如：

```text
dep@ubuntu:~$
```

此时你在 Mac 的窗口里操作 Ubuntu。

### 4.6 把项目拉到 Ubuntu

如果 Ubuntu 里还没有项目，运行：

```bash
git clone https://github.com/osifj/chip-cad-learning.git
cd chip-cad-learning
```

如果已经有项目，更新即可：

```bash
cd ~/chip-cad-learning
git pull origin master
```

### 4.7 在 Ubuntu 里运行项目

```bash
cd ~/chip-cad-learning
python3 -m pip install -r requirements.txt
bash scripts/check_all.sh
```

成功后继续按 Mac 部分的 Week 1-5 命令运行。

## 5. 每个项目怎么运行

### 5.1 01 Shell 环境脚本

项目目标：模拟 CAD 工程师入职时检查 Linux 工具、设置 EDA 环境变量。

对应能力：Linux、Shell、环境配置、license 变量理解。

运行：

```bash
cd 01-shell环境脚本学习
./eda_env_setup.sh --check-only
```

正常会看到：

```text
EDA Environment Setup Tool
>>> Running dependency check...
[PASS] gcc
[PASS] python3
[OK] tclsh installed
```

输出含义：

- `[PASS]`：工具存在且版本合适。
- `[OK]`：工具存在。
- `[WARN]`：能用，但版本可能偏旧。
- `[MISS]`：缺少工具。

常见错误：

- `Permission denied`：运行 `chmod +x eda_env_setup.sh`。
- `command not found`：确认你在 `01-shell环境脚本学习` 目录。
- Mac 上 `make v3.81 too old`：学习阶段可以继续；Linux/VM 上通常会是新版 make。

面试讲法：我写了一个 Shell 环境初始化脚本，用来检查 CAD 工作环境依赖，并统一设置 Synopsys、Cadence、Calibre、PDK 和 license 相关环境变量。

### 5.2 02 Tcl Log 解析器

项目目标：解析模拟 DC/PT log，提取指标。

对应能力：Tcl、正则、日志解析、IP QA。

运行：

```bash
cd 02-tcl-log解析器
tclsh eda_report_parser.tcl sample_logs/dc_synthesis.log -summary
```

正常会看到：

```text
aes_core_top | area=33142.10 | power=28.139 | cells=45231 | slack=-0.100 | violated=1 | warn=2
```

输出含义：

- `area`：总 cell 面积。
- `power`：总功耗。
- `cells`：单元数量。
- `slack`：最差时序裕量，负数代表 violation。
- `warn`：warning 数量。

常见错误：

- `tclsh: command not found`：Ubuntu 运行 `sudo apt install tcl`；CentOS 运行 `sudo dnf install tcl`。
- `log file not found`：确认路径 `sample_logs/dc_synthesis.log` 存在。

面试讲法：我用 Tcl 写了一个 EDA log parser，从综合和时序 log 中提取 area、power、cell count、worst slack 和 warning，用于自动生成 QA 摘要。

### 5.3 03 Python 测试数据流水线

项目目标：读取 testchip CSV，计算良率和参数统计。

对应能力：Python、pandas、测试数据分析、yield report。

运行：

```bash
cd 03-python测试数据流水线
python3 scripts/analyze_testchip.py data/testchip_measurements.csv --no-plot
```

正常会看到：

```text
Testchip Data Analysis Pipeline v1.0
加载数据: 40 行, 15 列
Yield: 97.5% (39/40)
Report saved: outputs/analysis_report.txt
```

输出文件：

```text
03-python测试数据流水线/outputs/analysis_report.txt
```

常见错误：

- `缺少依赖: pandas`：运行 `python3 -m pip install -r requirements.txt`。
- `文件不存在`：确认 CSV 路径是 `data/testchip_measurements.csv`。

面试讲法：我用 Python/pandas 做了 testchip 数据分析流水线，输入 CSV，输出良率、wafer 分组统计、speed bin 分布和参数统计报告。

### 5.4 04 EDA Flow 自动化

项目目标：模拟完整 EDA flow：synth -> place -> CTS -> route -> STA -> PV。

对应能力：Makefile、流程编排、日志管理、断点续跑。

运行：

```bash
cd 04-eda流程自动化框架
make all
make status
```

正常会看到：

```text
[SYNTH] OK
[PLACE] OK
[CTS] OK
[ROUTE] OK
[STA] OK
[PV] OK
```

输出文件：

- `logs/01_synthesis.log`
- `logs/05_sta.log`
- `flow/.synth_done` 等状态文件

常见错误：

- `make: command not found`：Ubuntu 安装 `sudo apt install make`。
- `bc: command not found`：STA 脚本需要 `bc`，Ubuntu 安装 `sudo apt install bc`。
- 想从头重跑：`make clean && make all` 或 `RESUME=0 make all`。

面试讲法：我用 Makefile 模拟了 reference flow，把综合、布局、CTS、布线、STA、PV 串起来，并用 `.done` 文件实现断点续跑和状态检查。

### 5.5 05 chipcad 工具箱

项目目标：用一个统一 CLI 调用前四周工具。

对应能力：内部工具封装、Python CLI、AI prompt 沉淀。

运行：

```bash
./05-chipcad工具箱与AI部署/chipcad.sh
./05-chipcad工具箱与AI部署/chipcad.sh parse 02-tcl-log解析器/sample_logs/dc_synthesis.log --format summary
./05-chipcad工具箱与AI部署/chipcad.sh analyze 03-python测试数据流水线/data/testchip_measurements.csv --no-plot
```

正常会看到命令帮助、Tcl 解析摘要、Python 分析报告路径。

常见错误：

- `Permission denied`：运行 `chmod +x 05-chipcad工具箱与AI部署/chipcad.sh`。
- `Unknown command`：先运行 `./05-chipcad工具箱与AI部署/chipcad.sh` 查看支持的命令。

面试讲法：我把环境检查、log 解析、数据分析和 flow status 统一封装成 `chipcad` 工具箱，减少重复命令，并加入 AI prompt 生成入口辅助脚本开发。
