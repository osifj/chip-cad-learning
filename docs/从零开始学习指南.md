# 从零开始学习指南：面向芯片 CAD 实习

这份仓库不是让你一次性背完所有代码，而是把岗位要求拆成可以运行、可以修改、可以讲清楚的 5 个小项目。

你的背景是香港大学 EEE 研究生、本科北京工业大学。这个背景已经足够切入芯片 CAD 实习；接下来最重要的是补齐工程脚本能力，并能解释自己做过的自动化工具。

## 0. 先理解这个岗位在做什么

岗位核心不是“画芯片”，而是用脚本把芯片设计、验证、测试中的重复工作自动化：

| JD 内容 | 仓库对应项目 | 你要能讲的话 |
|---|---|---|
| 设计数据版本管理自动化 | Week 1、Week 4、Week 5 | 我会用 Shell/Makefile 组织目录、环境变量、日志和运行状态 |
| 模拟电路设计流程自动化 | Week 4 | 我理解 flow step、日志、断点续跑、失败定位 |
| Reference Flow / Testchip 自动化 | Week 3、Week 4 | 我能处理测试数据，也能编排 mock reference flow |
| 版图流程自动化 | Week 4 | 我知道 place/CTS/route/PV 在流程中的位置 |
| IP QA 流程自动化 | Week 2、Week 4 | 我能解析 log、提取 warning/error/timing/slack |
| IP 测试数据收集、管理及分析 | Week 3 | 我能用 Python/pandas 做良率、参数统计和图表 |
| AI 工具部署与应用支持 | Week 5 | 我能把常用脚本能力封装成统一 CLI，并沉淀 prompt |

## 1. 第一次运行

在仓库根目录执行：

```bash
python3 -m pip install -r requirements.txt
./05-chipcad工具箱与AI部署/chipcad.sh
```

如果你在 Mac 上看到 `make v3.81 too old`，不用慌。macOS 自带 make 比较旧，学习脚本仍然能跑；真正入职或在 Linux VM 上一般会是 GNU Make 4.x。

## 2. 建议学习顺序

### Day 1：先跑，不求全懂

```bash
./05-chipcad工具箱与AI部署/chipcad.sh env check
./05-chipcad工具箱与AI部署/chipcad.sh parse 02-tcl-log解析器/sample_logs/dc_synthesis.log --format summary
./05-chipcad工具箱与AI部署/chipcad.sh analyze 03-python测试数据流水线/data/testchip_measurements.csv --no-plot
./05-chipcad工具箱与AI部署/chipcad.sh flow status
```

目标：知道每个命令的输入是什么、输出是什么、对应 JD 哪一条。

### Day 2：学 Shell 和 Linux 环境

重点看：

- `01-shell环境脚本学习/eda_env_setup.sh`
- `01-shell环境脚本学习/lib/check_deps.sh`
- `01-shell环境脚本学习/config/default.conf`

你要能回答：

- `PATH`、`LD_LIBRARY_PATH`、`LM_LICENSE_FILE` 分别有什么用？
- 为什么 EDA 工具需要环境变量？
- 脚本怎样判断一个命令是否安装？

### Day 3：学 Tcl 和 log 解析

重点看：

- `02-tcl-log解析器/eda_report_parser.tcl`
- `02-tcl-log解析器/sample_logs/dc_synthesis.log`
- `02-tcl-log解析器/sample_logs/pt_timing.log`

你要能回答：

- Tcl 的 `set`、`regexp`、`dict`、`proc` 分别怎么用？
- 怎样从 EDA log 里提取 WNS、cell area、warning？
- 为什么 log parser 对 CAD/QA 流程很重要？

### Day 4：学 Python 数据分析

重点看：

- `03-python测试数据流水线/scripts/analyze_testchip.py`
- `03-python测试数据流水线/data/testchip_measurements.csv`

你要能回答：

- CSV 每一列代表什么测试数据？
- 良率 yield 是怎么算的？
- 为什么要做异常值检测？
- Cpk 粗略反映什么？

### Day 5：学 Makefile 和流程编排

重点看：

- `04-eda流程自动化框架/Makefile`
- `04-eda流程自动化框架/scripts/run_*.sh`
- `04-eda流程自动化框架/scripts/flow_report.py`

你要能回答：

- 为什么 flow 要拆成 synth/place/cts/route/sta/pv？
- `.done` 文件为什么能实现断点续跑？
- 日志对排查失败有什么价值？

### Day 6：学统一工具箱和 AI 辅助

重点看：

- `05-chipcad工具箱与AI部署/chipcad.sh`
- `05-chipcad工具箱与AI部署/chipcad/cli.py`
- `05-chipcad工具箱与AI部署/prompts/`

你要能回答：

- 为什么要做统一 CLI？
- Python CLI 怎样调用 Shell/Tcl/Makefile？
- AI prompt 怎样帮助生成脚本，但为什么仍需要自己验证？

## 3. 面试时项目介绍模板

你可以这样讲：

> 我做了一个面向芯片 CAD 实习场景的自动化学习项目，把岗位中常见的环境配置、EDA log 解析、testchip 数据分析、reference flow 编排和 AI prompt 辅助封装成 5 个小工具。项目使用 Shell、Tcl、Python 和 Makefile。比如 Week 2 的 Tcl parser 可以从 DC/PT log 中提取 area、power、timing slack 和 warning；Week 4 用 Makefile 模拟 synth、place、CTS、route、STA、PV 的流程，并用 `.done` 文件实现断点续跑；Week 5 把前面工具统一成 `chipcad` 命令行入口。

## 4. 你现在最该补的基础

优先级从高到低：

1. Linux 基础命令：`cd`、`ls`、`pwd`、`cat`、`grep`、`find`、`chmod`、`ps`、`ssh`
2. Shell 脚本：变量、函数、if、for、退出码、重定向、管道
3. Tcl 基础：`set`、`proc`、`regexp`、`dict`、文件读写
4. Python 基础：函数、列表/字典、pandas 读 CSV、matplotlib 画图
5. Git 基础：clone、status、add、commit、push、pull
6. EDA 流程名词：synthesis、place、CTS、route、STA、DRC、LVS、PDK、license

## 5. 每天学习的正确姿势

每次只做三件事：

1. 跑一个命令。
2. 打开它调用的脚本，读懂 20 行。
3. 改一个小功能，再重新跑。

不要一上来追求“完全理解芯片全流程”。先把脚本跑通、把输入输出讲清楚，这就是 CAD 实习最需要的基本功。
