# 命令逐行解释手册

这份文档专门解释“每条命令到底是什么意思”。你不需要一次背完，运行到哪条就查哪条。

## 1. 基础命令

### `pwd`

```bash
pwd
```

- `pwd` 是 print working directory。
- 作用：显示你现在所在的文件夹。
- 为什么重要：很多报错都是因为你不在正确目录。
- 成功示例：`/Users/dep/Documents/Codex/2026-05-25/7-1-2-3-reference-flow`

### `ls`

```bash
ls
```

- `ls` 是 list。
- 作用：列出当前目录里的文件和文件夹。
- 如果看不到 `README.md` 和 `01-shell环境脚本学习`，说明你不在仓库根目录。

### `cd`

```bash
cd 02-tcl-log解析器
```

- `cd` 是 change directory。
- 作用：进入 `02-tcl-log解析器` 文件夹。
- 为什么要进入：里面有 Tcl 脚本和 sample log。
- 如果路径错了，会看到 `No such file or directory`。
- 用 `pwd` 确认是否进入成功。

### `cd ..`

```bash
cd ..
```

- `..` 代表上一级目录。
- 作用：从子项目目录回到仓库根目录。

## 2. 环境和依赖命令

### 安装 Python 依赖

```bash
python3 -m pip install -r requirements.txt
```

- `python3`：运行 Python 3。
- `-m pip`：用 Python 调用 pip。
- `install`：安装包。
- `-r requirements.txt`：从依赖清单读取要安装的包。
- 本项目会安装 `pandas`、`numpy`、`matplotlib`。
- 对应岗位能力：能准备脚本运行环境。

### 一键自检

```bash
bash scripts/check_all.sh
```

- `bash`：用 Bash 解释器运行脚本。
- `scripts/check_all.sh`：项目自检脚本。
- 作用：检查 Python、pip、Tcl、make，并跑核心 demo。
- 成功标志：看到多行 `[OK]` 和 `All core demos passed.`
- 失败时看 `[FAIL]` 后面的解决方法。

## 3. Week 1 Shell 环境脚本

### 进入 Week 1

```bash
cd 01-shell环境脚本学习
```

- 进入 Shell 环境脚本目录。
- 这里的主脚本是 `eda_env_setup.sh`。

### 只检查依赖

```bash
./eda_env_setup.sh --check-only
```

- `./`：运行当前目录下的程序。
- `eda_env_setup.sh`：Shell 主脚本。
- `--check-only`：只检查依赖，不设置完整环境。
- 输出里 `[PASS] gcc` 表示 gcc 可用。
- 对应岗位能力：Linux 环境检查、EDA tool setup。

### 模拟完整环境

```bash
SIMULATE=true ./eda_env_setup.sh
```

- `SIMULATE=true`：给脚本传一个临时环境变量。
- 作用：即使真实 EDA 工具目录不存在，也模拟设置环境变量。
- 适合学习，因为你现在没有真实 Synopsys / Cadence license。

### 保存报告

```bash
./eda_env_setup.sh --report setup_report.txt
```

- `--report setup_report.txt`：把报告保存到文件。
- 输出文件在当前目录：`setup_report.txt`。

## 4. Week 2 Tcl Log 解析器

### 解析 DC log

```bash
tclsh eda_report_parser.tcl sample_logs/dc_synthesis.log
```

- `tclsh`：Tcl 解释器。
- `eda_report_parser.tcl`：Tcl 解析脚本。
- `sample_logs/dc_synthesis.log`：输入 log 文件。
- 作用：解析综合报告，输出面积、功耗、时序等信息。
- 对应岗位能力：Log parsing、IP QA。

### 输出一行摘要

```bash
tclsh eda_report_parser.tcl sample_logs/dc_synthesis.log -summary
```

- `-summary`：只输出一行摘要，适合被其他脚本调用。
- 成功示例：`area=33142.10 | power=28.139 | slack=-0.100`

### 输出 JSON

```bash
tclsh eda_report_parser.tcl sample_logs/dc_synthesis.log -json
```

- `-json`：用结构化 JSON 格式输出。
- 用途：以后可以给 dashboard 或 Python 脚本读取。

### 保存报告

```bash
tclsh eda_report_parser.tcl sample_logs/dc_synthesis.log -o reports/dc_report.txt
```

- `-o`：output，指定输出文件。
- `reports/dc_report.txt`：报告保存位置。
- 如果 `reports` 目录不存在，需要先运行 `mkdir -p reports`。

## 5. Week 3 Python 测试数据分析

### 运行分析

```bash
python3 scripts/analyze_testchip.py data/testchip_measurements.csv --no-plot
```

- `python3`：Python 解释器。
- `scripts/analyze_testchip.py`：分析脚本。
- `data/testchip_measurements.csv`：输入测试数据。
- `--no-plot`：不生成图片，只生成文字报告。
- 输出文件：`outputs/analysis_report.txt`。
- 对应岗位能力：Testchip data analysis、测试数据自动化。

### 生成 HTML 报告

```bash
python3 scripts/analyze_testchip.py data/testchip_measurements.csv --report html
```

- `--report html`：输出网页格式报告。
- 输出文件：`outputs/analysis_report.html`。
- 如果同时生成图片，会看到 `outputs/01_histograms.png` 等文件。

### 指定输出目录

```bash
python3 scripts/analyze_testchip.py data/testchip_measurements.csv --output-dir outputs
```

- `--output-dir outputs`：把报告和图表放到 `outputs` 文件夹。

## 6. Week 4 Makefile / Flow

### 查看状态

```bash
make status
```

- `make`：根据 Makefile 执行任务。
- `status`：Makefile 里的一个目标。
- 作用：查看 synth、place、cts、route、sta、pv 是否完成。

### 跑全流程

```bash
make all
```

- `all`：跑完整 flow。
- 步骤：synth -> place -> cts -> route -> sta -> pv。
- 输出 log 在 `logs/`。
- 完成标记在 `flow/.xxx_done`。

### 从头重跑

```bash
RESUME=0 make all
```

- `RESUME=0`：关闭断点续跑。
- 作用：即使 `.done` 文件存在，也重新执行。

### 清理输出

```bash
make clean
```

- 删除 `flow/` 和 `logs/`。
- 适合重新练习。

### 指定设计名

```bash
DESIGN=my_chip make all
```

- `DESIGN=my_chip`：临时设置设计名。
- 日志里会显示 `my_chip`。

## 8. 常见错误速查

| 报错 | 原因 | 解决 |
|---|---|---|
| `No such file or directory` | 路径写错或目录不对 | 运行 `pwd`、`ls` 确认位置 |
| `Permission denied` | 脚本没有执行权限 | `chmod +x 脚本名` |
| `command not found: tclsh` | 没装 Tcl | Ubuntu: `sudo apt install tcl` |
| `缺少依赖: pandas` | Python 包没装 | `python3 -m pip install -r requirements.txt` |
| `make: command not found` | 没装 make | Ubuntu: `sudo apt install make` |
| `bc: command not found` | STA 脚本需要 bc | Ubuntu: `sudo apt install bc` |
| SSH 连接失败 | IP 变了或 VM 没开 | 在 VM 里运行 `hostname -I` |
